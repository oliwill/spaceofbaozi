# baozi.space 纸上拼贴与水彩角色设计

状态：Approved for implementation  
日期：2026-08-13  
适用范围：全站背景、页面纸张、启动动画、角色素材、照片、字体、导航、按钮与标签

## 1. 设计目标

baozi.space 使用“克制双层型”视觉系统：网站主体保持安静、清楚的编辑排版；人物、小狗、黄色球、启动页草地和极少量边注使用水彩剪纸。真实照片保持摄影材质，不转换为插画。

统一描述：

> 在一张被轻微减淡的无限点阵纸上，铺放几张暖白的大纸来整理文字和照片；包子与小狗则像带白边的水彩剪纸，在纸面上完成一段短小的定格动画，然后安静地留在首页。

该方向必须同时满足：

- 第一眼仍然是可阅读、可浏览的个人网站；
- 水彩角色建立个人辨识度，但不把全站变成儿童绘本；
- 背景、内容纸、照片和角色拥有清楚的材料层级；
- 动画结束后角色不持续漂浮或抢夺阅读注意力；
- 所有内容继续由真实 HTML、图片和内容数据构成，不将页面烘焙为整图。

## 2. 视觉架构

全站固定使用五层：

1. **环境层**：无限、低对比、浅灰蓝点阵背景。
2. **页面层**：铺在环境上的暖白大内容纸。
3. **内容层**：HTML 文字、真实照片、封面与数据。
4. **角色层**：水彩人物、小狗、球、草地与极少量角色边注。
5. **材料层**：相纸、纸签、胶带、印章和手写素材。

视觉面积目标：

| 组成 | 建议占比 |
| --- | ---: |
| 清晰 HTML 排版与留白 | 60% |
| 真实照片与封面 | 20% |
| 纸张层级与轻拼贴 | 12% |
| 水彩角色与手绘元素 | 8% |

水彩角色可以成为局部焦点，但不得扩展成全站栏目图标系统。

## 3. 无限点阵与内容纸

### 3.1 环境点阵

- 背景底色：`#EEF0EA`。
- 点阵颜色：`rgba(63, 78, 82, 0.14)`。
- 桌面点距：`22–24px`；移动端：`18px`。
- 点径：`1px`。
- 点阵原点全站固定，不随栏目或纸张重置。
- 页面中心和大纸附近通过极浅的遮罩减淡约 20%–30%；外侧留白的点阵略清楚。
- 减淡不得形成聚光灯、白色光晕或明确矩形遮罩。

“无限”只描述环境延伸，不允许访客自由拖拽或无限缩放画布。

### 3.2 暖白大纸

- 纸色：`#FFFDF7`。
- 桌面宽度：视口的 86%–90%，最大约 `1360px`。
- 大纸内部使用 12 列编辑网格。
- 相邻章节纸面允许重叠 `12–32px`。
- 绝大多数大纸保持端正；允许旋转不超过 `±0.3°`。
- 纸边只有轻微纤维感，不使用明显撕边和发黄做旧。
- 大纸阴影：`0 8px 30px rgba(46, 48, 42, 0.08)`。

一个视口通常只显示一张主纸、至多两张照片纸和一处小纸签。正文和栏目内容直接排在大纸上，不为每条内容创建独立悬浮卡片。

## 4. 启动页与转场

### 4.1 空间

- 启动页和首页共享同一无限点阵环境。
- 上方 74%–78% 保持浅灰绿色点阵纸。
- 下方 22%–26% 为水彩草地。
- 除“跳过动画”外不显示导航、标题和欢迎文案。
- 不绘制天空、太阳、云、树或完整风景。

### 4.2 草地

草地由稳定色块、不规则水彩上缘和极少量细线草叶构成：

| 用途 | 色值 |
| --- | --- |
| 主色 | `#839260` |
| 深部颗粒 | `#69784F` |
| 浅色水痕 | `#A8B486` |

草地上缘高度变化不得超过视口高度的 2%–3%。点阵可极轻微透过水彩，但不能呈现为简单的半透明绿色滤镜。

### 4.3 八拍叙事

1. 黄色球单独从左侧弹入。
2. 小狗从左侧追球。
3. 牵引绳绷紧，人物被拉入。
4. 人物和小狗共同向右跑。
5. 人物踉跄并向前摔倒。
6. 人物和小狗从启动页右侧离开。
7. 人物以连续姿态从首页左侧摔入。
8. 人物站起，小狗绕脚一圈后停下。

主运动方向始终向右。反向滚动只倒放时间线，不镜像角色。

### 4.4 转场

人物完全离开右侧后，在不可见区间完成：

1. 草地向下淡出或收回；
2. 无限点阵保持不变；
3. 暖白首页大纸出现在点阵环境上；
4. 人物以相同摔倒姿态从左侧进入大纸；
5. 白边角色可略微越过大纸左边缘。

禁止翻页、撞屏、闪白、黑场和同时出现两个人物副本。

## 5. 水彩剪纸角色

### 5.1 共同画法

- 深灰细墨线，不使用纯黑粗轮廓。
- 低饱和透明水彩，允许轻微越出线稿。
- 保留少量水痕、颜色浓淡和纸张颗粒。
- 增加暖白不规则剪纸边，颜色与大纸一致：`#FFFDF7`。
- 角色使用近距离投影：`0 3px 8px rgba(37, 35, 31, 0.12)`。
- 不做日漫脸、大头吉祥物、3D 高光或矢量扁平图标。

白边占最长边比例：

| 素材 | 白边比例 |
| --- | ---: |
| 人物 | 2.5%–3% |
| 小狗 | 3%–4% |
| 黄色球 | 3% |

小狗白边略厚，以免白毛在纸面上消失。

### 5.2 使用范围

水彩剪纸只用于：

- 启动动画人物、小狗、球与草地；
- 首页最终站立人物和小狗；
- About、404 与页尾中极少量角色延续；
- 与角色直接相关的少量手绘线条。

Blog、Photos、Shelf、Projects 不建立水彩图标系统。人物和小狗也不在每个栏目重复出现。

## 6. 定格动画语言

- 角色姿态以约 8–10 fps 切换。
- 角色水平移动仍由滚动时间线连续控制。
- 换帧可保留 1–2px 上下差异和不超过 `±0.5°` 的轻微旋转。
- 帽檐、衣摆、狗耳朵和尾巴允许逐帧变化。
- 不使用运动模糊、骨骼插值或持续弹性变形。
- 黄色球可有较明显的挤压与拉伸，但仍像纸片。
- 牵引绳使用手绘感 SVG 曲线；可以在少量预设线形之间切换，但必须保持两端锚定。
- 最终状态完全静止，不保留呼吸、漂浮和摇摆循环。

## 7. 照片与纸张材料

### 7.1 真实照片

- 保留真实摄影材质，不转换为水彩。
- 只允许轻微统一曝光、白平衡和饱和度。
- 使用哑光相纸或拍立得式白边；相纸白边规则且比角色白边更窄。
- 主图旋转不超过 `±1°`；小图不超过 `±1.5°`。
- 不为每张照片添加胶带、图钉或撕边。

### 7.2 材料种类

全站主要只保留三种纸：环境点阵、暖白大纸和照片纸。Now 或短边注可以使用少量米白／淡色小纸签。

每个视口最多：

- 一处胶带；
- 一个印章；
- 一至两条手写边注；
- 一个局部不超过三层的堆叠。

所有素材共享左上方光源，投影统一向右下：角色阴影最近，照片稍宽，大纸最柔和。

## 8. 字体系统

### 8.1 字体角色

| 用途 | 字体 | 字重 |
| --- | --- | ---: |
| 标题、章节名、引语 | 思源宋体 SC | 500 / 600 |
| 正文、导航、按钮、标签、元数据 | 系统无衬线字体栈 | 400 / 500 / 600 |
| 手写边注 | 定制 SVG 或图片素材 | 不作为正文字体 |

不再加载独立等宽字体。日期和数字使用系统无衬线字体配合 `font-variant-numeric: tabular-nums`。

生产站只自托管标题实际使用的思源宋体简体中文 WOFF2 子集；正文不加载完整思源黑体。字体失败时回退至系统宋体和系统无衬线，不影响布局。

### 8.2 字号

| 层级 | 桌面 | 移动端 | 行高 |
| --- | ---: | ---: | ---: |
| 首页主标题 | 52–60px | 38–44px | 1.15 |
| 文章 H1 | 44–52px | 34–40px | 1.2 |
| 分区 H2 | 30–36px | 26–30px | 1.3 |
| 卡片 H3 | 21–25px | 19–22px | 1.4 |
| 正文 | 17–18px | 16–17px | 1.75–1.85 |
| 导航 | 14–15px | 14px | 1 |
| 标签、元数据 | 12–13px | 12px | 1.4 |

中文正文每行约 34–42 个汉字。标题不使用夸张字距，不使用全大写英文正文。

## 9. 导航、按钮和标签

### 9.1 白纸索引导航

桌面导航采用从暖白大纸右上边缘微微露出的五个索引标签：

> Blog　Photos　Shelf　Projects　About

- 标签高 34–38px，从大纸上缘露出 12–16px。
- 基本色与大纸接近，不使用五种不同颜色。
- 当前栏目只选择一种主状态：淡靛蓝纸色或朱红短线。
- 上方两个圆角约 4px，下方与大纸衔接。
- hover 上移约 2px，不旋转。
- 启动动画开始时导航不可见；人物进入首页、开始站起时逐渐出现。
- 移动端保持单行横向滚动；空间不足时再评估折叠菜单。

导航固定使用简短英文栏目名。页面标题和分区标题使用中文，不再出现同义中英双标题。

### 9.2 按钮

按钮分三级：

1. **文字链接**：用于阅读全文、查看全部、进入相册和查看项目；通过下划线与箭头移动反馈。
2. **纸片按钮**：用于联系、下载、返回和跳过动画；暖白背景、1px 墨灰边框、5px 圆角、轻投影。
3. **图标按钮**：只用于灯箱和翻页等标准控制；点击区域至少 40×40px，具有明确可访问名称。

所有按钮的键盘焦点：`2px solid #284D5B`，偏移 `3px`。禁止胶囊按钮、渐变主按钮和营销式 CTA 文案。

### 9.3 标签与筛选

- 内容标签：12–13px、墨灰文字、浅色细边框、3–4px 圆角；每条内容最多显示三个；不强制 `#`。
- 栏目筛选：使用较小纸张索引结构；选中态为淡靛蓝底色，并有非颜色状态提示。
- 项目状态：固定为 `idea · 构想中`、`building · 制作中`、`shipped · 已完成`、`archived · 已归档`。
- 标签不旋转，不随机着色，不与筛选按钮使用完全相同的交互外观。

## 10. 响应式与降级

- 移动端重新排版，不缩小桌面纸张拼贴。
- 大纸左右留出 12–20px 环境点阵；复杂叠放、胶带和边注减半。
- 移动端开场后续压缩至约 200vh，但保留完整因果链。
- `prefers-reduced-motion: reduce` 直接显示首页最终站立状态。
- 素材加载失败时显示大纸、内容、人物和小狗的稳定替代状态，不阻塞网站。
- 开场结束后角色停止一切循环动作。

## 11. 验收标准

- 背景点阵可见但不抢文字，中心减淡没有明显光圈。
- 每个大章节是一张主要大纸，不是卡片墙。
- 人物、小狗和球拥有真实 Alpha、暖白剪纸边与统一投影。
- 小狗白毛边缘完整，没有被背景移除工具吞掉。
- 角色姿态有定格感，位置移动仍然连续且可逆。
- 第一拍只有球，主运动始终向右。
- 草地占视口 22%–26%，不构成完整风景。
- 真实照片没有被水彩化。
- 同屏只出现宋体标题、系统无衬线正文和极少量定制手写素材。
- 导航为白纸索引，不是五张彩色便利贴。
- 页面内部不重复相同含义的中英文标题。
- 动画最终状态完全静止，不干扰首页阅读。

## 12. 明确禁止

- 将水彩风扩展到所有栏目图标、照片和正文 UI；
- 把真实照片转换成统一水彩滤镜；
- 五种彩色便利贴导航；
- 每条内容一张独立悬浮纸卡；
- 粗大纯白表情包描边；
- 大头吉祥物、日漫脸和儿童绘本比例；
- 多套手写字体、独立等宽元数据字体和无意义中英重复；
- 角色持续呼吸、漂浮、晃动或眨眼；
- 明显聚光灯式网格减淡；
- 木门、实体手账、翻页、撞屏和自由拖拽无限画布。

## 13. 实施边界

本设计只改变视觉与素材生产要求，不改变已经确认的信息架构和首轮实现范围。仍先完成：

1. 水彩剪纸 Sprite 的生产工程化；
2. 桌面 `/lab/intro` 原型；
3. 首页大纸与最终角色落点；
4. 原型通过后再扩展全站页面和移动端。

书面规范已经确认。旧 implementation plan 不再有效，实施必须使用新的双轨计划：本地 harness 负责契约、占位素材、动画代码和验证；生产图像由独立视觉流程提供，按固定 Manifest 无代码替换。

## 14. 图片素材双轨交付

本地 harness 不调用任何图片生成能力，也不负责重新设计人物、小狗或动作。两条轨道的边界如下：

| 轨道 | 负责 | 不负责 |
| --- | --- | --- |
| Harness | Manifest、调试占位 Sprite、动画、回退、审计与测试 | 生成、补画、重绘生产图像 |
| 视觉素材 | 真实 Alpha、暖白剪纸边、逐帧一致性、锚点、生产 WebP | 页面逻辑与滚动时间线 |

Harness 可以先用明显的调试占位素材完成 `/lab/intro`，但默认访问必须请求生产目录；生产素材缺失时直接进入稳定首页，不允许访客看到调试占位图。生产素材交付后只替换固定路径中的文件和 Manifest 数据，时间线代码不得随之重写。

点阵环境、暖白大纸、草地主体、牵引绳、纸签、按钮和标签均由 HTML/CSS/SVG 构成，不依赖图片生成。真实照片继续由内容工作流和 PicGo 管理，不进入角色 Sprite 流水线。

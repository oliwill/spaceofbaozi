# baozi.space PRD v2.1 修订提案

**状态：** 草案，待用户批准后落回 `baozi-space-prd.md` 正文
**日期：** 2026-08-13
**依据：** D-106（design-spec v2.0 交接包成为唯一设计事实来源）

> 本文件只列出需要修改的节。未列出的 PRD 章节（§5 栏目定义、§6 内容模型与编辑规则、§8 技术约束、§9 无障碍门槛、§10 优先级、§11 验收剧本 C–F、§13 Open Questions 内容部分）继续有效。

## 修订总原则

1. design-spec v2.0 管「视觉、动效、构图、响应式」；PRD 管「页面目标、信息需求、内容责任、发布门禁」。同一主题两份文档冲突时，以 design-spec 为准。
2. PRD 的标记约定（Confirmed / Requirement / User Input / Open）不变。
3. 所有门禁与内容真实性规则（`draft: false && approved: true`、占位禁令、妳称谓）不受视觉方向变化影响。

---

## §0 执行摘要

- **§0.1 产品一句话**：重写为「个人档案与个人工作空间；在一张无限延伸的暖白点阵纸上，用杂志级网格整理个人档案，再以少量剪贴簿触感留下生活痕迹」。删除「活页本、抽卡」描述。
- **§0.3 当前项目阶段**：更新为「设计规范 v2.0 已锁定；A0 素材工程化进行中；阶段路线 A0 → A1 → B → C → D」。
- **§0.4 核心边界**：删除「活页本、抽卡和翻页是空间隐喻」；新增「开场动画是可跳过叙事，不是加载器」「天气失败不阻塞进入」。

## §1 产品定义

- **§1.2 产品目标 G3**：视觉系统描述改为 design-spec §4.1 的定义（点阵纸 + 编辑拼贴 + 安静杂志）。
- **§1.4 产品原则**：第 2 条「物理隐喻解释结构」改为「动作讲故事：大动效必须推动叙事」（spec §1.2-5）。
- **§1.3 非目标**：不变；可补充「可自由拖拽缩放的无限画布」（spec §15 已废弃）。

## §3 信息架构

- **§3.1 路由树**：整体替换为 design-spec §2.2 基线路由：

  ```text
  / 首页 · /blog · /blog/thoughts · /blog/[slug]
  /photos · /photos/[slug]
  /shelf · /shelf/[type]/[slug]
  /projects · /projects/[slug]
  /about · /lab/intro（实验页，不进导航）
  ```

  旧路由跳转表：`/drinks/*` → 对应 `/blog/*` 或 `/shelf` 标签页（逐条确认）；`/books/*`、`/music/*`、`/movies/*` → `/shelf/[type]/[slug]`；`/thoughts/*` → `/blog/*`；`/ai-works/*` → `/projects/*`；`/about/me` → `/about`。全部逐条永久跳转的规则不变。
- **§3.3 导航契约**：七栏目条款整体替换——「一级导航只含 Blog / Photos / Shelf / Projects / About 五项；Drinks 等作为标签存在」。「七栏目首发各 ≥1 条」门禁改为「五个一级栏目各 ≥1 条真实已批准内容；Shelf 内部 Books / Movies / Music 每类 ≥1 条」。
- **§3.4 首页两个状态**：整节删除。替换为 spec §6.2 首屏构图（左侧身份区 / 右侧 Blog / 底部 Photos 预告 / 左上天气）+ §7 开场叙事。Launch / Home 概念废止；「每个会话播放一次开场」由 sessionStorage 规则（spec §7.6）承接。

## §4 页面需求

- **§4.1 Launch**：整节删除（FR-LAUNCH-01~15 全部废止）。其「身份与用途在五秒内可理解」目标由新首页身份区 + 开场叙事承接。
- **§4.2 Home**：重写为 spec §6.2 + §6.3：首屏左身份区右 Blog，后续分区顺序 Blog → Photos → Shelf → Projects → About → Footer。编辑规则（首要内容精选、最近更新 3 条、featured 唯一性阻塞）保留不变。
- **§4.3 栏目归档**：五条栏目各写一页目标（spec §6.4–6.9）；发布门禁条款 FR-ARCHIVE-01~11 保留，栏目集合替换。
- **§4.4 详情页**：保留；视觉细节（单列 720px、跨列大图、MetaStrip）指向 spec §6.5。
- **§4.5 About**：保留 User Input 清单；补充 spec §6.9（Now 必须有更新时间、不用简历模板）。
- **§4.6 404 / SEO**：保留；补充「动画跳过按钮与灯箱关闭按钮使用明确中文可访问名称」（spec §11.4）。

## §5 V2 栏目产品定义

- 栏目表替换为五个一级栏目；原 Books / Music / Movies 行移入 Shelf 小节，字段与补充要求**逐条保留**（评分禁令、currentlyReading、kind: movie|series、观看事件、热力图规则均不因合并而丢失）。
- Drinks 行删除，记录其内容未来以 Blog 文章或 Shelf 标签形态存在。
- 「全站写作称谓（妳）」保留。

## §6 内容模型与编辑规则

- **§6.1 schema**：补充新字段建议：`type`（Shelf 条目区分 book/movie/music）、`status`（项目 idea/building/shipped/archived + 中文解释，spec §6.8）、`externalUrl`。`approved` / `updated` / `coverAlt` / `coverCredit` 门禁字段不变。
- **§6.2 发布要求**：Photos / Project / Drinks / Books / Music / Movies 补充要求中，Drinks 段删除，其余保留。
- **§6.3 schema 缺口**：保留；书影音热力图与豆瓣导入映射在 Shelf 合并后继续有效。
- **§6.4 首页编辑规则**：保留（featured 唯一、最近更新 3 条、approved 过滤），与新首屏构图兼容。
- **§6.5 占位内容**：保留不变。

## §7 交互、响应式与降级

- §7.1 卡片抽取、§7.2 打开活页本、§7.3 页面翻页：**整节删除**，替换为 spec §7（开场动效规范）与 §9（动效系统：时长层级、hover ≤3px、缓动曲线、reduced-motion）。
- §7.4 响应式：替换为 spec §10（桌面优先 1440×900；平板 8 列；移动端 4 列重排，装饰减半；断点 768 / 1100）。

## §8 技术与维护约束

- §8.1 保留清单：加入 GSAP + ScrollTrigger、Vitest、Playwright、Sharp、Python rembg/Pillow（开发期）；「Obsidian 内容维护路径」保留。
- §8.2 渐进增强：保留，补充开场动画四回退（reduced-motion / 跳过 / 会话完成 / 素材失败）。
- §8.3 发布完整性：保留；补充性能预算（首屏 ≤1.5MB、开场资源 ≤6MB，spec §12.6）。

## §11 验收剧本

- A（第一次访问）：重写为开场叙事验收（八镜头顺序、跳过、reduced-motion）。
- B（手机访问）：开场移动端属于阶段 D，本期验收只检查内容可读与导航可用。
- C–F：保留。

## §12 阶段与放行标准

- Phase 划分整体替换为 spec §13 的 A0 / A1 / B / C / D；旧 Phase 0–7 记录归档。
- Phase 2 不可变约束（Launch/Home 画板）整节删除，其历史由 D-104 → D-105 → D-106 链承接。

## §13 Open Questions

- OQ-01~09、12、15、17、18（已关闭）：保留为历史。
- OQ-10、11、13、14、16（未关闭）：保留，Owner 与最迟阶段重新映射到新阶段（Phase 4 → 阶段 B，Phase 2 → 阶段 A1 前，Phase 6 → 阶段 C）。
- 新增：**OQ-19** 天气数据源（粗粒度 IP 城市推断的提供方与隐私边界）；**OQ-20** Drinks 既有占位内容的最终去向（Blog 文章 or Shelf 标签）。

# 首页重建设计：单页平铺网点纸（Layout Guideline v1）

**日期：** 2026-07-24
**状态：** 已与包子确认，进入实现
**依据：** `baozi-space-spec.md` §3.5（2026-07-24 生效）、`baozi-space-prd.md` 第一/二/七章、`baozi-space-assets.md` §6–7

## 1. 背景与目标

现有首页仍是已过时的双页跨页基线（`page-left` / `page-seam` / `page-right`）。本次重建为 §3.5 定义的**单页平铺网点纸**：一张纸主导视口，物件像被包子慢慢贴上去（Accumulation over Composition），不是被排版出来的。

## 2. 已确认决策

| 决策 | 结论 | 来源 |
|---|---|---|
| 布局 | 单页平铺，1200×800 设计坐标系；禁止九宫格 / Bento / 等宽卡片 | spec §3.5 |
| 入口名单 | Blog（主锚点）、Thoughts、Photos、About 四个；其余物件纯装饰 | spec §3.5 |
| 占位视觉 | 纯文字纸张入口（手写标签 + 纸片/胶带/圈画），不摆空壳图、不放假物件 | 用户确认 2026-07-24；PRD §7.3 空状态规则 |
| 进入交互 | 两步：浮现栏目名 → 再点进入；取代旧的自动过渡页 | spec §3.5 |

## 3. 结构与构图

### 3.1 坐标系与缩放

- `.paper` 固定 1200×800，物件绝对定位，构图以像素坐标表达。
- ≥660px：CSS `scale: min(100vw/1200px, 100vh/800px)` 等比缩放整张纸，构图与相对位置不变；无 JS 依赖。
- <660px：media query 切换——`.paper` 变宽度 100% 纵向流，物件 `position: static` 重排为垂直列表，入口可点区域 ≥44px，装饰 `display: none`（日期印章保留）。

### 3.2 构图（S 型视觉流）

DOM 顺序 = 阅读顺序 = Tab 顺序：

```text
1200 × 800 单页
+--------------------------------------------------------------+
| 下午好，欢迎光临中华一番包子铺        [日期印章]   baozi.space |
| 这里不是博客，也不是商店。                                     |
| 是一本会不断变厚的数字手账。                                   |
|                                                              |
| ┌─ 撕边纸片（胶带）────────┐      ┌ 便利贴（淡黄）─┐          |
| │ Blog  文章记录            │      │ 突然想到……      │  [待整理  |
| │ 01 · 最近更新 ✎           │      │ Thoughts       │   纸签]  |
| └──────────────────────────┘      └───────────────┘   (可拖) |
|                                          ╲ 手绘箭头           |
|                        ┌─ 圈画 ─────────┐   ╲                |
|                        │ Photos 胶片与生活 │                   |
|                        └─────────────────┘                   |
| 记录中 →                              ┌─ 小纸签 ──────────┐  |
|                                       │ About 你好，我是包子 │  |
|                                       └───────────────────┘  |
+--------------------------------------------------------------+
```

- **主锚点 Blog**：撕边纸片 + 胶带，约 340×220（视觉面积 ~28%，落在 25–32% 区间），手写大标题。
- **Thoughts**：CSS 便利贴（淡黄，物件而非背景色），约 200×190。
- **Photos**：文字标签 + 手绘圈画/箭头（SVG 线稿，Mode I 气质）。
- **About**：小纸签 + 胶带，约 240×110。
- **装饰**：日期印章（D 类，`mix-blend-mode: multiply`）、1 个手绘箭头、1 张可拖动「待整理」纸签、零散手写小字。
- 角度：入口 |θ| ≤ 5°，装饰 ≤ 8°；间距不用统一数值；入口互不重叠。
- 覆盖度估算 ~18%（≤ 60% 上限），留白 ≥ 40% 成立。

### 3.3 纸张

白底 `--paper` + 浅灰点阵 `--grid-dot`（沿用现有令牌与网点实现）；外部背景 `--page-bg` 仅作衬托。无米黄/牛皮纸。

## 4. 交互模型

### 4.1 开本

1. 加载 → 合上的封面（沿用现有 FREITAG 风 CSS 封面）。
2. 短延迟后进入 `is-opening`（封面翻离，≤900ms）→ `is-open`（单页显现，物件轻微错峰落位）。
3. `prefers-reduced-motion`：直接 `is-open`，无动画；导航额外延迟 ≤100ms。
4. 「↻ 重新打开」辅助按钮保留，不抢占首个入口焦点。
5. JS 失败：封面下仍有语义链接？—— 降级策略：`is-closed` 状态下入口链接在 DOM 中可被无 JS 浏览器直接访问的方案过重；采用 PRD 既有降级——JS 不可用时展示静态栏目链接列表（`<noscript>` 或初始无 `is-closed` 类，由 JS 负责合上）。**决定：初始 HTML 即为打开态，JS 加载后才执行「合上→打开」**，无 JS 时直接可读可点。

### 4.2 两步进入

- 悬停 / 键盘聚焦：浮现手写栏目批注（编号 + 栏目名 + 一句话，如 `01 · Blog · 文章记录`）。
- 指针点击：鼠标 hover 已满足「浮现」，点击即进入（pointerdown 记录 pointerType，`mouse`/`pen` 直接放行）。
- 触屏：首次 tap 只浮现批注（`is-primed`），二次 tap 进入；点他处或 Esc 取消 primed。
- 键盘：聚焦即浮现，Enter 一次进入。
- 全部入口始终是 `<a href>`，JS 仅增强；`prefers-reduced-motion` 下点击直接导航。
- 反馈只作用于当前悬停项，其余入口保持安静。

### 4.3 拖动

- 仅「待整理」装饰纸签可拖：Pointer Events + `setPointerCapture`，4px 阈值内视为静止；位置限制在纸面内；位移除以纸张当前 scale；`touch-action: pan-y` 保证纵向滚动优先。
- 不持久化，刷新复位。

## 5. 实现

重写三个文件，干净切换、不留兼容层：

- `src/pages/index.astro`：单页结构；入口数据来自 `src/lib/sections.ts`（单一事实源）；初始打开态，JS 负责开本；删除双页 markup、`page-seam`、`section-overlay`。
- `src/styles/journal.css`：单页布局 + 纸张 + 物件样式 + 缩放/重排媒体查询；沿用 global.css 令牌；port 封面样式。
- `public/scripts/journal.js`：开本、时区问候/日期印章、两步进入、装饰拖动；删除 overlay 逻辑。

其它：

- 手写批注沿用 `neat-annotations.css`（若复用价值低则内联少量 SVG，实现时定）。
- 新增中文文案后跑 `bun run fonts:subset`。
- 封面暂为纯 CSS；`cover@A-.webp` 到位后替换为图片（≤150KB，首屏预算内）。
- `demo/` 归档不动。

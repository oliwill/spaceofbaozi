# baozi.space v2.1 项目重构路线图

**状态：** Current

**日期：** 2026-08-13

**依据：** D-106、D-107、`docs/design/baozi-space-design-spec.md` v2.1

## 1. 目标

把当前 D-105 数字手账生产基线逐步迁移为 v2.1：固定原点的低对比点阵环境、暖白大内容纸、五个一级入口，以及可跳过的水彩剪纸开场。迁移期间保持现有 Astro 静态站可构建，不提前破坏旧 URL，也不把调试占位素材暴露给访客。

## 2. 两种结构状态

### 当前可运行基线

```text
src/content/{blog,thoughts,photos,drinks,books,music,about,ai-works}
src/pages/                 # D-105 首页、旧栏目路由、BookSpread 详情
src/components/layout/
src/styles/{global,home}.css
public/scripts/{cover-open,site-experience}.js
```

这部分是迁移输入，不是 v2.1 视觉事实来源。A0-H / A1 不改动它的内容集合和正式路由。

### v2.1 目标结构

```text
docs/design/               # 全站设计规范与材料系统
docs/intro/                # 开场动画、素材和 Manifest 契约
design-assets/intro/       # 非公开源稿、参考、外部交付与 QA
public/assets/intro/
  placeholders/            # 仅显式开发 / 测试模式
  production/              # 默认运行时资产
scripts/intro-assets/       # 占位生成、审计、发布
src/components/intro/      # 语义舞台
src/lib/intro/             # Manifest、帧、绳索、加载、时间线
src/pages/lab/intro.astro
src/content/{blog,photos,shelf,projects,about}/
src/pages/{blog,photos,shelf,projects,about}/
tests/{unit/intro,e2e}/
```

## 3. 迁移原则

1. 先增加隔离的 `/lab/intro`，再替换首页；A1 不依赖内容迁移。
2. A0-H 与 A0-V 通过固定 Manifest 并行，生产图片交付不得要求重写时间线。
3. 旧内容先建立逐条迁移表和重定向断言，再移动文件或删除旧路由。
4. `approved`、`updated`、`coverAlt`、`coverCredit` 与模板、所有查询和发布门禁在同一阶段切换。
5. D-105 的 `BookSpread`、手写字体和等宽元数据字体不继续扩展；阶段 C 完成替代模板后删除，不保留兼容样式层。
6. handoff 目录是原始交接快照；实施只引用 `docs/design/`、`docs/intro/` 和本计划。

## 4. 阶段路线

### A0-H · 素材契约与占位轨道

**输入：** `docs/intro/asset-production-contract.md`、`design-assets/intro/source/`。

**实施：**

- 建立 `src/lib/intro/assetManifest.ts`，验证六个固定动作、4×2 网格、8 帧、锚点、模式与 fallback。
- 用 Sharp + SVG 生成明显的几何 placeholder，不模仿生产水彩图。
- 建立 placeholder / incoming / production 审计与原子发布脚本。
- 增加生产目录 placeholder 泄漏门禁。

**放行：** 六张占位 Sheet 有真实 Alpha、尺寸和锚点正确、总负载低于 6MB；默认访问仍选择 production。

### A0-V · 外部视觉轨道

**输入：** 已确认的人物、小狗、球源稿与参考。

**实施：** 外部流程交付六张透明 WebP、一张最终静态图和生产 Manifest；本仓库只暂存、审计、生成 contact sheet 和发布。

**放行：** 48 帧人工 QA 通过；白毛、暖白衬衫、眼镜、帽檐、手指和青色项圈完整；所有角色朝右；负载不超过 6MB。

### A1 · 桌面 `/lab/intro`

**输入：** 已通过的 A0-H 接口；几何开发使用显式 placeholder。

**实施：**

- Astro 语义舞台 + GSAP ScrollTrigger + DOM/CSS Sprite + SVG leash。
- 300vh、sticky 100svh、八个归一化叙事区间和可逆滚动。
- 跳过、会话完成、reduced motion、素材和 Manifest 失败回退。
- 固定 0%、8%、25%、45%、65%、82%、94%、100% 截图。

**放行：** 1440×900 八节点与回滚通过；1280×720、1920×1080 smoke test 通过；正式视觉批准等待 A0-V。

### B · 首页整合

**前置：** A1 几何评审通过，A0-V 生产素材通过审计。

**实施：**

- 重写 `src/pages/index.astro` 与首页样式，删除 sticky 封面和五页手账结构。
- 建立固定点阵环境、暖白大纸、天气 / 时间回退、五项索引导航。
- 首屏左侧身份区、右侧单一 Blog 主视觉、底部 Photos 预告。
- 后续按 Photos → Shelf → Projects → About → Footer 排列。
- 将开场完成状态接到相同 DOM 几何；无 JS 直接渲染稳定首页。

**放行：** 设计规范测试视口、键盘、200% 缩放、reduced motion、首屏 ≤1.5MB。

### C · 全站页面与内容迁移

**前置：** 首页布局和五项 IA 已稳定。

**实施顺序：**

1. 建立共享 v2.1 页面 shell 与 design tokens，替代纸张手账 chrome。
2. Blog：合并经批准 Thoughts，保留 `/blog/thoughts` 类型入口。
3. Photos：保留相册语义，建立可访问灯箱。
4. Shelf：建立 `type: book | movie | music` 判别 schema 和类型专用页面。
5. Projects：迁移经批准 AI Works，采用固定项目状态。
6. About：迁移批准内容和 Now 更新时间。
7. Drinks：逐条确定目标，不做整栏盲迁移。
8. 建立旧 URL 永久跳转测试，随后删除旧路由模板、旧 collections 和 BookSpread。
9. 同步 `approved` 等通用治理字段、模板、所有查询与发布门禁。

**放行：** 每个旧公开 URL 有明确目标或 Retire 决策；没有双份正文；旧 collection 名和 D-105 视觉组件无运行时调用方。

### D · 移动端与扩展

重排 4 列移动布局，完成约 200vh 的简化开场和触摸验证。冬季整套 Sprite 可选，不能混入夏季资产，也不阻塞 MVP。

### E · 内容、发布与运维

完成真实内容批准、图片来源、SEO、OG、favicon、404、RSS / 匿名统计取舍、Cloudflare Preview、生产域名和回滚演练。

## 6. 全局验证

每阶段至少执行：

```powershell
bun run check
bun run build
```

引入测试与资产脚本后追加：

```powershell
bun run test:unit
bun run test:e2e
bun run assets:intro:audit:placeholder
bun run assets:intro:audit:production
```

验证必须覆盖可观察行为，不以文件存在或构建成功替代浏览器场景。

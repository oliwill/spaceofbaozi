## 当前可回滚基线：D-105 数字手账首页（2026-08-12 落地）

- `src/pages/index.astro` 的当前生产实现属于 D-105：sticky 全屏封面 + 下滑开本 + 五页结构（P.01 Blog / P.02 Photos / P.03 书影音 / P.04 Project / P.05 页尾），详情页为 `BookSpread` 跨页。

- 回滚方式：保留 Git 历史，并在 CP7 发布时标记可回滚的 commit / tag；不维护第二套并行实现。
- 已知结构问题（v2.1 已废弃，不做局部视觉修补）：额外入口门槛、书脊 / 翻页 / 满屏纸页隐喻、低对比小字号、同义中英双标题、独立等宽元数据、悬浮卡片墙、空栏目整页与弱导航。

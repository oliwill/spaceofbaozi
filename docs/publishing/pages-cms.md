# Pages CMS 日常维护

Obsidian + Sync 是写作主本；Pages CMS 用来手工维护网站副本。目前只完成本地候选配置，托管 CMS 连接、实际保存格式和真实手机首发／更新尚未验证。以下保存与上线步骤须在对应接入、验证和发布流程分别获准后执行。

仓库已经公开。CMS 草稿、上传的图片和 Git 历史都可能公开；`draft` 与 `approved` 只控制网站是否输出文章。所有送入 CMS 的文字和图片必须先确认可公开。

## 首发

1. 在 Obsidian 完稿，等待 Sync 完成。切到阅读模式，通读正文，检查链接和图片。指向已公开笔记的双链改成最终公开 URL；目标无法确认时先停止，人工整理后再继续。
2. 为选定图片准备压缩后的网页副本。上传前检查整张画面、截图中的姓名／通知、来源与使用许可，以及定位等元数据；需要移除的内容先在本机处理，再检查结果。CMS 不会自动清理元数据。为正文图准备准确的 Alt，封面另填描述与来源。
3. 在 CMS 核对目标仓库、分支和“文章”集合。新建时手工确定稳定英文短横线文件名，例如 `my-first-post.md`（合成示例）；文章位于 `src/content/blog/`。检查对应 URL，后续修订始终使用此文件，不新增 `slug` 字段。
4. 粘贴公开正文，不复制 Obsidian 的私人属性、备注或未确认链接。逐张上传已检查的图片并替换正文链接；图片媒体源为 `blog_images`，写入 `public/assets/blog/`，正文使用 `/assets/blog/图片文件名.webp` 等逻辑路径。可切到 Source 模式检查 Markdown。若网站部署在项目子路径下，由网站处理前缀，不手工重复添加。
5. 核对标题、摘要、标签、首次发布日期 `date`（`yyyy-MM-dd`）、正文链接、封面、`coverAlt` 和 `coverCredit`。保留已有文章的可选 `featured`、`status`、`link` 原值。未修订时 `updated` 留空，实际保存后的文件必须省略这个键。
6. 新稿默认使用真实布尔值 `draft: true`、`approved: false`。只有包子明确批准正文、图片和来源后，才在同一次正文保存中改为 `draft: false`、`approved: true`。不把布尔值写成带引号的字符串。确认文件名与字段后保存。
7. 查看 GitHub 对应文件和提交，确认正文、图片路径及字段。首次托管验证尤其要检查空 `updated` 是否被省略：若写成空字符串或 `null`，停止接入并报告差异，不继续真实内容保存或自行添加插件。
8. 发布路线另行启用后，查看对应提交的 Actions 结果，再打开真实文章 URL，核对正文、图片与手机显示。保存成功、构建进行中、网站已上线和失败是不同状态；CMS 的保存提示不能证明上线。

**图片上传可能立即产生 GitHub 提交，即使最终没有保存正文。** 取消文章编辑不会撤回已上传图片，媒体与文章保存并非原子操作。未引用图片也可能公开；系统不承诺自动清理原图、孤立文件或共享图片。`public/` 资产不受文章门禁保护，不能放入私人照片。

## 更新与主本同步

先在 Obsidian 修改正文并等 Sync，再从 CMS 的原文章进入。核对原文件名、URL 与首次 `date`，改标题或正文也保留它们；有修订时按需填 `updated`，否则省略该键。重复首发中的图片检查、字段核对、保存和后续验收步骤。

若临时在 CMS 改了正文，先手工把最终版本复制回 Obsidian，并等 Sync 完成，再继续写作。CMS 不会自动回写 Obsidian，也不会自动合并两端修改。

## 断网、上传失败与冲突

断网、上传失败、出现同名图片，或多设备同时修改时，先停止重试，保存本地待改文字。查看 GitHub 的文件、文件 SHA 和提交记录，核对哪次图片上传或文章保存已经发生，再与 Obsidian 主本比较。无法判断时暂停并请维护者协助，不连续点击保存或覆盖远端文件。

同名图片先确认远端文件是否被其他文章引用；需要新图时使用另一个明确文件名，不盲目覆盖或删除。确定最终版本后，先整理主本、等 Sync，再从最新远端文章继续；始终保留原文章文件名和首发日期。

## 后续接入范围

账号权限、真实样稿保存、手机首发／更新，以及 DNS、上线和回滚执行仍待单独授权。接入时需审查实际 GitHub App 权限页面并批准选定的单个仓库；不要在聊天中提供密码或令牌。表单只显示 Blog、禁用文章重命名与删除属于界面限制，不是 GitHub 权限沙箱，也不保证媒体删除已禁用。

本文不授权发布操作。拟公开内容与兼容路径见 [公开范围简表](publication-inventory.md)。

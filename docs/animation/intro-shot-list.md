## 1. 适用范围

本文冻结 Seedance 生成输入的 0.0–6.0 秒分镜、桌面与移动第一帧、共同 `handoff-final`、角色身份参考和交接坐标。CP2 Seedance、CP3 后期、CP4 Rive 与网站集成都必须消费本合同，不得各自重做首尾构图。

CP1 不生成 Seedance 视频。本文中的“一致性通过”只表示输入首帧、目标末帧及其坐标合同通过预检；实际生成视频的首尾帧比较仍是 CP2 门禁。

## 3. 首尾帧定义

### 3.1 第一帧

- 固定机位；整幅为低对比点阵环境，下方为 B-lite 水彩草地。
- 桌面为 `1440×900`，移动为 `390×844`；两端均是独立构图，不做桌面裁切。
- 第 0 帧无人、无狗、无球、无牵引绳、无首页大纸、无文字、无导航、无控件。黄色小球在播放开始后才从左侧进入。
- 背景与草地在整段视频中固定，不漂移、不呼吸、不变形。

### 3.2 最终帧

- `handoff-final` 必须由真实 `/lab/home-v2?capture=video-plate` 导出，不得由手工合成、遮盖或 AI 重画获得。
- 最终帧保留点阵环境、暖白大纸、水彩洗色、人物、嘉乐、地面阴影和底部靛蓝下一分区色块；HTML 文案、天气、导航、CTA、栏目文字与 Astro 调试工具栏全部隐藏。
- Capture mode 仅以 `visibility` 隐藏 UI，不改变布局。完整 Home v2 与无 UI 尾帧的人物、嘉乐、阴影、大纸和下一分区矩形必须逐项同坐标。
- 6.0 秒必须收敛到对应 `handoff-final`；最后 3 帧完全静止。DOM/UI 在视频层上方独立出现，不烘焙进视频。

## 5. 角色身份参考

### 人物

- `person-reference.png` 直接来自批准的夏季生产设定源表，包含正面、左右侧、背面、渔夫帽、圆框眼镜、印花短袖、深蓝短裤、鞋、手表、表情与跑姿。
- 输出最长边 2400px；只做等比重采样，不从首页小图放大，不重新生成身份。
- 中间帧必须保持同一张脸、服装图案、身体比例、水彩纸纹和白色剪纸描边。

### 嘉乐

- `jiale-reference.png` 直接来自批准的嘉乐生产设定源表，包含正面、左右侧、背面、脸型、耳朵、尾巴、脚掌、毛发和青色项圈。
- 输出最长边 2400px；只做等比重采样，不从首页小图放大，不重新生成身份。
- 中间帧必须能判定为同一只白色小型犬；禁止改变犬种、项圈颜色、体长或头身比。

### 风格

- `style-reference.png` 只包含生产点阵纸、B-lite 草地、水彩斑驳、角色白描边和暖白 / 绿色 / 深蓝 / 黄色色板，不含文字、历史方案或网页 UI。

## 6. 0.0–6.0 秒冻结分镜

| 时间 | 画面与动作 | 冻结约束 |
| --- | --- | --- |
| `0.0–0.7s` | 小号黄色球从左侧进入草地，向右滚动并轻微弹跳。 | 第 0 帧无球；球足够小，可被嘉乐衔住；背景固定。 |
| `0.7–1.8s` | 嘉乐从左侧追球进入。 | 同一只白色嘉乐，青色项圈不丢失；四足跑动，无滑步。 |
| `1.8–3.3s` | 单根牵引绳拉紧，人物从左侧被嘉乐带入，踉跄后追跑。 | 手部、项圈和绳端关系清楚；同一人物与服装。 |
| `3.3–4.6s` | 人物与嘉乐继续向右并略向观众靠近。 | 透视自然；脸、比例、衣服图案、白边与水彩质感不变。 |
| `4.6–5.2s` | 人物失去平衡，以身体和暖白纸形成自然全屏遮挡。 | 不撞击镜头、不画碎玻璃、不摇镜；该处是两段式回退拼接点。 |
| `5.2–6.0s` | 遮挡后显现 Home v2 无 UI 尾帧，人物站稳、嘉乐停下。 | 收敛到 canonical `handoff-final`；最后 3 帧完全静止。 |

全程单镜头、固定机位、无切镜、无声音。嘉乐始终领先人物，主运动始终左进右出。桌面与移动动作顺序相同，但移动空间路径独立安排。

## 7. 全段禁止项

- 无文字、乱码、Logo、水印、导航、按钮、字幕、浏览器工具栏、鼠标、滚动条、声音或音轨。
- 无镜头推拉、摇移、旋转、变焦、景深变化、抖动、切镜或背景呼吸。
- 无 `scaleX(-1)`、角色突然换脸、换衣、换犬种、换描边、比例跳变或塑料 3D 质感。
- 无额外人物、第二只狗、多余肢体、腿部融合、分叉牵引绳、黑帧、白闪或玻璃碎裂。
- 牵引绳允许 CP3 后期覆盖，但不得因绳子细节降低人物与嘉乐身份门槛。

## 8. Harness 预检

`harness-cp1-audit.json` 已实际读取七张成品并验证：

- 桌面首尾帧均为 `1440×900`；移动首尾帧均为 `390×844`。
- 人物与嘉乐参考最长边均为 2400px；风格板为 `2400×1400`。
- Capture mode 的 UI 全部隐藏；完整页面与无 UI 尾帧的稳定几何完全相同。
- 桌面 29,403 个、移动 20,994 个差异像素全部位于 UI 区域；稳定背景 / 角色区域差异像素为 0。
- 首尾帧均为完整不透明画面；不依赖伪透明棋盘格。

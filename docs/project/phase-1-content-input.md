### 4.2 豆瓣书影音数据来源（后置事项）

**调研结论（2026-07-30）：** 不建议让正式网站实时抓取或爬取豆瓣页面。

- 豆瓣当前法律声明明确限制未经书面许可的数据采集、爬虫、数据摘录及基于豆瓣内容开发其他网站；书影音基础信息、评分、评论和标记记录也在其列举范围内。
- 豆瓣官方隐私政策提供 App 内“设置 → 个人信息导出”，可以申请个人信息副本；但公开说明没有承诺导出文件一定包含完整书影音字段。
- 豆瓣曾提供个人评论 RSS，但可查到的官方说明来自 2005 年，不应视为当前稳定 API 合同。

**推荐方式：导入，不做实时同步。**

1. 包子从豆瓣 App 申请“个人信息导出”；
2. 将导出包作为本地输入交给 Codex 检查，不提交账号信息或其他敏感数据；
3. 只导入包子自己的标记、评分、短评和原始链接，转换为本站本地 Markdown / JSON；
4. 不默认复制豆瓣评分、封面或其他平台专有数据；
5. 每次导入先生成 Git diff，由包子批准后发布；
6. 正式网站只读取仓库内已批准内容，豆瓣不可用时也不影响网站。

如果导出包不包含书影音记录，安全回退为用户维护的 CSV / JSON 模板，或在本站手动新增记录并保留 `sourceUrl` 指向对应豆瓣页面。

官方依据：

- <https://www.douban.com/about/privacy?page=2026-05-20>
- <https://www.douban.com/about/legal>
- <https://blog.douban.com/douban/2005/04/22/14/>

### 4.3 Books / Music / Movies 独立页面（已确认方向）

用户当前优先关注页面如何呈现，数据同步方式后置。原始构想：

1. 页面最顶部使用活动热力图，并显示累计统计；
2. 中段呈现“最近在看 / 最近在听”等 Top 3 或 Top 5 内容；
3. 页面底部呈现包子的人工推荐。

已确认：

- Books、Music、Movies 分别使用独立页面，不增加统一“书影音总览”页；
- 三页可以共用信息骨架和基础组件，但不能把不同类型的数据强行使用同一种统计口径；
- 每页分别呈现本栏目的热力图、统计、最近状态、人工推荐与完整归档入口。
- 热力图统计“完成或主动记录事件”，不统计每天的阅读时长或逐次播放行为：
  - **Books：** 每条书籍记录最多贡献一次，优先使用读完日期；没有读完日期时使用主动建档日期；
  - **Movies：** 每次实际观看完成贡献一次；重看可以作为新的观看事件；
  - **Music：** 每条主动记录的专辑或歌单贡献一次；不把单曲播放次数或流媒体播放量计入热力图。
- 热力图默认显示当前自然年 1–12 月，并允许切换往年；本年数量与全部累计分开显示，未来日期为空白，不制作无限长度的全历史热力图。
- 最近状态数量：
  - **Books：** 正在读 Top 3；
  - **Movies：** 最近看过 Top 5；
  - **Music：** 最近在听 Top 5。
- 桌面端完整展示对应数量；手机端 Books 直接展示 3 条，Movies / Music 默认看到前 3 条，后 2 条通过隐藏滚动条的横向轮播访问。
- 横向轮播不自动播放；需保留下一项露出或位置提示，并支持触摸、触控板、键盘和辅助技术访问。
- 每个页面的人工推荐区使用同一编辑规则：
  - 1 个重点推荐 + 最多 4 个普通推荐；
  - 全部由包子人工选择，不依据平台评分、热度或算法生成；
  - 每条必须提供一句“为什么推荐”；
  - 不强制按月更新，可以长期保留；
  - 推荐数量不足时展示实际数量，不生成占位内容。
- 栏目主页不直接展开完整历史列表，固定顺序为：
  1. 年度统计与热力图；
  2. 正在读 / 最近看过 / 最近在听；
  3. “查看全部记录”入口；
  4. 位于页面最下方的人工推荐。
- 完整记录使用独立归档页：
  - `/books/archive`
  - `/movies/archive`
  - `/music/archive`
- 归档页负责年份、状态、标签筛选和完整列表；栏目主页保持有限长度，推荐区不会被历史记录压到过深位置。

    - 如果预览环境、迁移过程或异常状态中仍出现空栏目：
      - 保留稳定 URL；
      - 页面和主页目录标记为“正在整理”；
      - 页面设置 `noindex`；
      - 不参与人工精选、最近更新或全站更新时间；
      - 第一条公开且已批准内容发布后，根据有效内容数量自动移除“正在整理”和 `noindex`，不依赖人工切换另一枚状态开关。

> “空栏目”只是一种防御性回退，不是 V2 计划上线状态。生产发布校验必须在构建或部署前阻止任何一个内容栏目以零条有效内容上线。

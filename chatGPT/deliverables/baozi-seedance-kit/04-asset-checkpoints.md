# 后续素材 Checkpoints

## CP1-A：生成输入冻结

- [ ] 桌面首帧 1440×900 已由包子确认。
- [ ] 移动首帧 390×844 已由包子确认。
- [ ] 桌面/移动无 UI 尾帧由真实 Home v2 导出，不是 AI 重画。
- [ ] 完整首页截图只进入 `review-only`，不上传 Seedance。
- [ ] 人物高清设定表包含正、左、右、背四面。
- [ ] 嘉乐高清设定表包含正、左、右、背四面。
- [ ] 动作参考无浏览器 UI、鼠标、音轨和旧首页画面。
- [ ] `handoff-coordinates.json` 已填写并锁定。

出口：所有生成输入只有一个版本并标记 `approved`。

停止：角色参考仍是首页小图放大、尾帧仍包含 DOM 文字时，不开始付费生成。

## CP2-A：桌面样片

- [ ] Seedance 2.5、16:10、6 秒、24fps、无声。
- [ ] 只生成 3 条并记录任务 ID、提示词、参考文件和时间。
- [ ] 人物脸、帽子、眼镜、衣服图案、手脚数量稳定。
- [ ] 嘉乐脸型、耳朵、蓝项圈、尾巴和四肢稳定。
- [ ] 背景不漂移，相机不移动。
- [ ] 最后一秒能收敛到无 UI 尾帧。
- [ ] 除绳子和少量遮罩外，不需要逐帧重画角色。

出口：至少一条评分表总分 ≥80，且身份、固定镜头、尾帧三项无否决。

停止：最多 6 条仍无合格候选时，切换两段式生成；两段式仍失败则改用 Rive/人工关键帧。

## CP3-A：后期与移动版

- [ ] 后期重绘单根牵引绳并逐帧跟踪手部/项圈。
- [ ] 修复边缘闪烁、局部穿模和最后一帧抖动。
- [ ] 桌面母版锁定后再独立生成移动版。
- [ ] 移动版不是桌面裁切，角色始终留在安全区。
- [ ] 最后 3 帧保持完全静止。
- [ ] 移除全部音轨和生成元数据中的非必要内容。
- [ ] 保留无压缩/高码率母版，再生成 Web 版本。

出口：桌面与移动母版均通过逐帧检查。

## CP3-B：Web 资产

- [ ] `intro-desktop.webm` ≤4.5MB。
- [ ] `intro-mobile.webm` ≤3MB。
- [ ] 同时提供 H.264 MP4 回退源。
- [ ] Poster 与视频第一帧完全一致。
- [ ] 浏览器只下载匹配视口的一份视频。
- [ ] Chrome、Safari、Firefox 均可播放。

出口：关键开场资源总负载 ≤6MB，画质没有因压缩破坏白边、点阵和草地。

## CP4：Home 互动素材

- [ ] 人物拆分：身体、头部、前景手臂、阴影。
- [ ] 嘉乐拆分：躯干、头、耳朵、前后腿、尾巴、阴影。
- [ ] Rive 先完成一个象限，不先做整圈。
- [ ] 水彩纹理和白边在变形时不呈塑料矢量感。
- [ ] Rive 不通过时，准备 16 方位 × 4–6 步态帧 WebP 回退。

出口：嘉乐无滑步和重影，人物重心稳定，静止后停止渲染循环。

## CP5：视频与网页交接

- [ ] 视频尾帧层和 Home 实时角色层使用同一坐标与枢轴。
- [ ] DOM UI 在视频层上方独立出现，不烘焙进视频。
- [ ] 正常播放、跳过、会话完成、减弱动态、媒体失败均进入同一 Home v2。
- [ ] 交接不依赖超过 200ms 的明显淡化。

出口：交接前后人物脚底、嘉乐中心、纸张原点和分区顶部无肉眼跳变。

## CP6–CP7：验收与发布

- [ ] 五个视口录屏：1280×720、1440×900、1920×1080、390×844、430×932。
- [ ] 播放丢帧率目标 <2%。
- [ ] 慢网、解码失败、无 JS、reduced motion、第二次访问全部测试。
- [ ] 生产 CDN 缓存、Range Request 和真实下载体积通过。
- [ ] D-105 回滚 tag/commit 可用并完成一次演练。

出口：自动化全绿且包子完成最终视觉确认。

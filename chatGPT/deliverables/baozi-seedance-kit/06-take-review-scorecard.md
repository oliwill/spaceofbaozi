# Seedance 样片评分表

先检查否决项，再评分。任何否决项失败都不能进入后期。

## 否决项

- [ ] 人物全程是同一身份，无变脸、换衣、帽子/眼镜消失和多余肢体。
- [ ] 嘉乐全程是同一只狗，无第二只狗、项圈消失、尾巴/腿数量变化。
- [ ] 固定机位，背景无可见漂移、呼吸或缩放。
- [ ] 最后一秒能自然进入批准的无 UI `handoff-final`。
- [ ] 不需要逐帧重画人物或嘉乐。

| 总分 | 100 |  |

通过线：总分 ≥80，且所有否决项通过。

牵引绳单独分级：

- A：可直接使用。
- B：可通过跟踪重绘修复。
- C：绳子问题伴随手部、身体或嘉乐结构变形，不可修复。

# 6 秒开场冻结分镜

镜头规则：一个固定机位、无切镜、无声音。网页 UI 不属于生成视频，由 DOM 负责。

| 时间 | 画面动作 | 物理与身份门禁 | 后期预留 |
| --- | --- | --- | --- |
| 0.0–0.7s | 黄色球从左侧进入并滚动 | 球足够小；背景完全静止 | 可调整球轨迹 |
| 0.7–1.8s | 嘉乐追球进入 | 同一只白色比熊；四足跑动；蓝项圈不丢失 | 可修耳朵/尾巴局部闪烁 |
| 1.8–3.3s | 绳子拉紧，人物被带入 | 单根绳；手部和项圈逻辑正确；人物同一服装 | 绳子最终重绘，不因绳子淘汰身份稳定的样片 |
| 3.3–4.6s | 两者向右并略向观众靠近 | 正确透视；脸、比例、衣服图案和白边稳定 | 允许小范围速度重映射 |
| 4.6–5.2s | 人物失衡，暖白纸形成全屏遮挡 | 不撞碎屏幕；不摇镜；无白闪 | 作为两段式拼接点 |
| 5.2–6.0s | 显现 Home v2 无 UI 尾帧 | 人物与嘉乐准确落位；背景与分区色块一致 | 最后 3 帧冻结；DOM 在此阶段叠加 |

## 不可协商的连续性

- 动线始终左进右出。
- 嘉乐始终领先人物，牵引绳只表达“嘉乐把人物带入”。
- 人物接近镜头时不能突然长高、变壮或变成不同画风。
- 最后定帧不从 AI 视频截图反推；始终以 CP0 批准的 Home v2 为源头。
- 桌面和移动共用动作表，不共用空间轨迹。

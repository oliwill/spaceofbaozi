# Seedance 2.5 提示词

## 生成参数

- 模式：全模态参考生视频／首尾帧控制。
- 时长：6 秒。
- 画幅：桌面 16:10；移动 9:16。
- 帧率：24fps。
- 声音：无对白、无环境声、无音乐；导出后仍需移除音轨。
- 第一轮：桌面 720p，连续生成 3 条，保留每条任务 ID。

## 桌面主提示词

```text
制作一段 6 秒、16:10、单镜头、固定机位的手绘水彩网站开场动画。

严格使用 @图1 作为第一帧，严格使用 @图2 作为最后一帧。@图3 是唯一的人物身份与服装参考，@图4 是唯一的嘉乐身份与体型参考。只参考 @视频1 中“黄色球先进入、嘉乐追球、牵引绳拉紧、人物被带入并加速”的动作顺序和节奏，不参考 @视频1 的旧页面、裁切、最终落点或任何界面元素。

画面保持 B-lite 手绘水彩与轻微印刷斑驳感：暖白低对比点阵纸，画面下方约四分之一是绿色水彩草地；人物和嘉乐始终有清晰、稳定、厚度一致的白色贴纸描边。主色只有绿色、暖白和深蓝，黄色只用于小球。人物始终戴深蓝渔夫帽和眼镜，穿浅色印花短袖衬衫、深蓝短裤和深色鞋。嘉乐始终是同一只白色比熊犬，佩戴同一条蓝色项圈，脸型、耳朵、尾巴和体型全程不变。

0.0–0.7 秒：一只足够小、可以被嘉乐叼住的黄色球从画面左侧进入草地，向右滚动并轻微弹跳，运动遵守真实重力。
0.7–1.8 秒：嘉乐从左侧追球进入，四足跑动自然，脚掌接触草地，没有滑步；尾巴和耳朵只做轻微惯性摆动。
1.8–3.3 秒：单根牵引绳被拉紧，人物从左侧被嘉乐带入画面。人物握绳的手、嘉乐蓝色项圈和绳子的连接关系清晰。人物踉跄后开始追跑，身体重心和脚步符合真实惯性。
3.3–4.6 秒：人物与嘉乐继续向右并略微朝观众靠近，透视自然增加，但人物与嘉乐的脸、服装、比例、白色描边和水彩质感不发生变化。
4.6–5.2 秒：人物失去平衡向画面前方扑来，以人物身体和一张暖白纸形成自然的全画面遮挡；不要撞击镜头，不要画碎玻璃，不要摇晃镜头。
5.2–6.0 秒：遮挡后显现 @图2 的 Home v2 无 UI 状态。人物已经站稳，嘉乐停在指定位置。最后 3 帧完全静止并与 @图2 像素构图一致。

全程只有一个连续镜头。相机绝对固定：无推拉、无摇移、无旋转、无变焦、无景深变化、无镜头抖动。点阵纸和草地绝对静止，不呼吸、不漂移、不变形。画面中不出现文字、字母、数字、Logo、导航、按钮、字幕、水印或声音。

身份稳定优先于牵引绳细节；牵引绳允许后期覆盖，但不得因此生成额外手臂、额外腿、第二只狗或改变人物姿态。
```

## 移动版提示词

在桌面提示词前加入以下覆盖说明，并把首尾帧替换为移动端文件：

```text
这次生成独立的 9:16 移动端版本，严格使用移动 @图1 和移动 @图2。不要裁切或缩放桌面视频。保持同样的 6 秒动作顺序，但重新安排横向距离：球、嘉乐和人物始终完整留在安全区内；人物和嘉乐不得进入顶部文字预留区；最后一帧人物与嘉乐必须完全回到移动 @图2 的位置。相机仍然完全固定。
```

## 两段式回退方案

若连续两轮都无法同时完成“复杂摔倒”和“精确尾帧”，不要继续抽单条 6 秒视频：

1. A 段生成 4–5 秒追逐动作，以人物和暖白纸完全遮满画面结束。
2. B 段生成最短允许时长，以相同暖白遮挡开始、以 `handoff-final` 结束；后期只取最后约 1–1.5 秒。
3. 在 100% 暖白遮挡处拼接，再统一到 6 秒。

这样可以把复杂运动和像素级交接拆开，同时保留“单镜头感”。

## 定向修复提示词

### 角色漂移

```text
保持原视频的动作、节奏、固定镜头和背景完全不变，只修复人物与嘉乐的身份。人物全程严格匹配 @图3；嘉乐全程严格匹配 @图4。不要修改镜头、草地、球、运动轨迹和最后一帧。
```

### 背景漂移

```text
锁定点阵纸与水彩草地为完全静止的二维背景层，只保留球、嘉乐、人物和牵引绳运动。不得改变角色动作和最后一帧构图。
```

### 最后一秒不稳定

```text
保持前 5 秒不变，只修复最后 1 秒，使角色平稳收敛到 @图2。最后 3 帧完全静止，不允许缩放、平移、换姿势、换色或白边闪烁。
```
